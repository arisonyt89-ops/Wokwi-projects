# Project 01: Button-Controlled LED (Arduino Uno)

Первый проект по микроконтроллерам и электронике, демонстрирующий чтение цифровых сигналов с использованием внутреннего подтягивающего резистора (INPUT_PULLUP) и условной логики if / else на C++.

## Компоненты схемы
- Arduino Uno
- Pushbutton (Кнопка)
- LED (Светодиод, красный)
- Resistor (Резистор 220 Ом)

## Подключение (Wiring)
- **Анод светодиода (A) -> Резистор 220 Ом -> Pin 13**
- **Катод светодиода (K) -> GND**
- Кнопка (контакт 1.L) -> Pin 2
- Кнопка (контакт 2.R) -> GND

## Логика работы
Пин кнопки настроен в режиме INPUT_PULLUP. При нажатии линия замыкается на землю (LOW), срабатывает условие if и загорается светодиод на пине 13.
